## Описание проекта

Приложение предназначено для ведения банка данных граждан из льготных категорий на предприятии 
и предоставление им льгот в соответствии с законодательными и нормативными актами Российской Федерации.

## Основные функции приложения

### 📊 Управление данными льготников
- **Пополнение и корректировка** банка данных информацией о льготниках
- **Добавление, просмотр и редактирование** информации о гражданах
- **Корректировка и пополнение** справочников льгот

### 📝 Журналирование и отчетность
- **Ведение «Журнала событий»** - запись действий сотрудников при работе с приложением
- **Фильтрация «Журнала событий»** по сотруднику и дате
- **Формирование отчета** «Журнала событий» в Excel с учетом выбранных фильтров

### 📈 Аналитика и отчеты
- **Генерация отчетов** по льготным категориям (Word/Excel)
- **Формирование статистических отчетов** по количеству льготников различных категорий
- **Создание диаграмм** различных видов по количеству льготников различных категорий (Excel)

### 🏛️ Администрирование и документооборот
- **Регистрация справок**, которые были выданы льготным категориям граждан
- **Регистрация пользователей** системы
- **Хеширование паролей** для обеспечения безопасности

## Технические особенности

- **REST API** для интеграции с внешними системами
- **JWT аутентификация** для безопасного доступа
- **Поддержка Excel/Word** для экспорта отчетов
- **Система ролей** для разграничения прав доступа
- **Логирование всех действий** для аудита

## API Endpoints

### 🔐 Аутентификация
- `POST /api/v1/auth/token` - получение JWT токена
- `POST /api/v1/auth/register` - регистрация новых пользователей

### 👥 Управление гражданами
- `GET /api/v1/citizens` - список всех льготников
- `POST /api/v1/citizens` - добавление нового льготника
- `GET /api/v1/citizens/{id}` - получение информации о льготнике
- `PUT /api/v1/citizens/{id}` - обновление данных льготника
- `DELETE /api/v1/citizens/{id}` - удаление льготника

### 📋 Управление льготами
- `GET /api/v1/privileges` - список всех льгот
- `POST /api/v1/privilege` - добавление новой льготы
- `PUT /api/v1/privileges/{id}` - обновление льготы

### 📄 Управление справками
- `GET /api/v1/certificates` - список всех справок
- `POST /api/v1/certificates` - выдача новой справки
- `GET /api/v1/certificates/{id}` - информация о справке

### 📊 Отчеты и аналитика
- `GET /api/v1/reports/events` - журнал событий с фильтрацией
- `GET /api/v1/reports/events/excel` - экспорт журнала в Excel
- `GET /api/v1/reports/privilages/excel` - экспорт журнала в Excel
- `GET /api/v1/reports/citizens/excel` - экспорт журнала в Excel
- `GET /api/v1/reports/statistics` - статистика по льготникам
- `GET /api/v1/reports/statistics/excel` - экспорт статистики в Excel
- `GET /api/v1/reports/excel/full-report` - все данные в одном отчете
- `GET /api/v1/reports/charts/certificates-timeline` - диаграммы по категориям

## Безопасность

- 🔒 **JWT токены** для аутентификации
- 🗝️ **Хеширование паролей** по алгоритму bcrypt
- 👮 **Система ролей** (admin, user, viewer)
- 📝 **Логирование всех действий** для аудита
